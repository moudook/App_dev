### 3. Implement Event-Driven Architecture

**Current State:** Synchronous request-response

**Suggestion:** Use message queue for async operations

**Use Cases:**
- Research sessions (long-running)
- Image generation (async processing)
- Digest generation (scheduled)
- Sync operations (background)

**Implementation:**
```kotlin
// Using Kotlinx Coroutines Channels
class EventBus {
    private val channel = Channel<AppEvent>(Channel.BUFFERED)
    
    fun publish(event: AppEvent) {
        channel.trySend(event)
    }
    
    fun subscribe(type: KClass<out AppEvent>): Flow<AppEvent> {
        return channel.consumeAsFlow()
            .filter { type.isInstance(it) }
    }
}
```

**Benefits:**
- Better scalability
- Decoupled components
- Natural async handling

**Effort:** 40-60 hours
**Priority:** Medium

### 4. Add Caching Layer

**Current State:** Limited caching (LlmCache exists)

**Suggestion:** Implement multi-level caching

**Proposed Cache Structure:**
```kotlin
class CacheManager {
    // L1: In-memory (frequently accessed)
    private val l1Cache = CacheBuilder.newBuilder()
        .maximumSize(1000)
        .expireAfterWrite(5, TimeUnit.MINUTES)
        .build<String, Any>()
    
    // L2: Redis (shared across instances)
    private val l2Cache = redisClient.cache()
    
    // L3: Database (persistent)
    private val l3Cache = database.cacheTable()
}
```

**Cache Candidates:**
- User settings
- Category lists
- Common search results
- LLM responses (with TTL)

**Benefits:**
- Reduced database load
- Faster response times
- Better scalability

**Effort:** 16-24 hours
**Priority:** High
