**Release:**
```kotlin
buildTypes {
    release {
        isMinifyEnabled = true
        isShrinkResources = true
        proguardFiles(
            getDefaultProguardFile("proguard-android-optimize.txt"),
            "proguard-rules.pro"
        )
        signingConfig = signingConfigs.getByName("release")
        buildConfigField("String", "SERVER_URL", 
            System.getenv("SMARTY_SERVER_URL") ?: "\"https://your-space-name.hf.space\"")
    }
}
```

### Signing Configuration

```kotlin
signingConfigs {
    create("release") {
        storeFile = file("../friday-release-key.keystore")

        keyAlias = System.getenv("FRIDAY_KEY_ALIAS")
        keyPassword = System.getenv("FRIDAY_KEY_PASSWORD")

}
```

### ABI Splits

```kotlin
splits {

        isEnable = true
```

## SERVER BUILD

### Build Configuration

```kotlin
plugins {
    application
    kotlin("jvm")
    id("com.github.johnrengelman.shadow") version "8.1.1"
}

application {
    mainClass.set("com.example.smarty.server.ApplicationKt")
}
```

### Shadow JAR

```kotlin
tasks.named<com.github.johnrengelman.gradle.plugins.shadow.tasks.ShadowJar>("shadowJar") {
    archiveClassifier.set("all")
    manifest {
        attributes["Main-Class"] = "com.example.smarty.server.ApplicationKt"
    }
    mergeServiceFiles()
}

tasks.build {
    dependsOn(tasks.named("shadowJar"))
}
```

### Build Commands

**Build JAR:**
```bash
./gradlew :server:shadowJar
```

**Run Server:**
```bash
./gradlew :server:run
```

**Build Full:**
```bash
./gradlew build
```

### Build Output

**JAR Location:**
```
server/build/libs/server-1.0.0-all.jar
```

**JAR Size:** ~50-100MB (fat JAR with all dependencies)

## DOCKER BUILD

### Multi-Stage Build

**Stage 1: Dependencies**
```dockerfile
FROM gradle:8.12.1-jdk17-alpine AS deps
WORKDIR /build
COPY build.server.gradle.kts build.gradle.kts
COPY settings.server.gradle.kts settings.gradle.kts
COPY gradle.properties ./
COPY server/build.server.gradle.kts server/build.gradle.kts
COPY common/build.server.gradle.kts common/build.gradle.kts
COPY gradle/ gradle/
COPY gradlew ./
RUN ./gradlew :server:dependencies --no-daemon || true
```

**Stage 2: Builder**
```dockerfile
FROM deps AS builder
WORKDIR /build
COPY common/src/commonMain/kotlin/ common/src/commonMain/kotlin/
COPY server/src/ server/src/
RUN ./gradlew :server:shadowJar --no-daemon --parallel -x test
```

**Stage 3: Runtime**
```dockerfile
FROM eclipse-temurin:17-jre-alpine
RUN addgroup -S appgroup && adduser -S -G appgroup -u 1000 user
WORKDIR /app
COPY --from=builder --chown=user:appgroup /build/server/build/libs/server-1.0.0-all.jar app.jar
USER user
ENV SERVER_PORT=7860
EXPOSE 7860
CMD ["java", "-Xmx384m", "-XX:+UseG1GC", "-jar", "app.jar"]
```

### Build Optimizations

1. **Dependency Caching**
   - Dependencies downloaded in separate layer
   - Rarely changes, heavily cached

2. **Source Layer Separation**
   - Source code in separate layer
   - Changes frequently, rebuilds fast

3. **JRE Runtime**
   - JRE only (no JDK)
   - Minimal image size (~100MB total)

4. **Non-Root User**
   - Security best practice
   - UID 1000 for Hugging Face Spaces

### Docker Commands

**Build Image:**
```bash
docker build -t smarty-server .
```

**Run Container:**
```bash
docker run -p 7860:7860 \
    -e DB_URL=jdbc:postgresql://host:5432/db \
    -e DB_USER=user \
    -e DB_PASSWORD=pass \
    -e TAVILY_API_KEY=key \
    smarty-server
```

**Run with Docker Compose:**
```bash
docker-compose up -d
```

## HUGGING FACE SPACES DEPLOYMENT

### Deployment Steps

1. **Create Space**
   - Go to https://huggingface.co/spaces
   - Click "Create new Space"
   - Name: `smarty-server`
   - SDK: Docker
   - Template: Blank

2. **Connect Repository**
   - Link GitHub repository
   - Or push directly

3. **Configure Secrets**
   - Go to Space Settings → Repository secrets
   - Add required secrets (see config_env.txt)

4. **Deploy**
   - Push to main branch
   - Space automatically rebuilds

5. **Verify**
   ```bash
   curl https://your-space.hf.space/health
   ```

### Space Configuration

**File:** `README.md` (frontmatter)
```yaml
---
title: Smarty - Advanced AI Agent(AAA)
colorFrom: purple
colorTo: blue
sdk: docker
pinned: true
license: mit
---
```

### Deployment Notes

1. **Restart Required After Secret Changes**
   - Secrets are loaded at container start
   - Must restart Space for changes to take effect

2. **Build Time**
   - First build: 5-10 minutes
   - Subsequent builds: 2-5 minutes (cached layers)

3. **Resource Limits**
   - CPU: 2 vCPU (free tier)
   - RAM: 16GB (free tier)
   - Storage: Limited

## CI/CD CONFIGURATION

### GitHub Actions (Recommended)

**File:** `.github/workflows/build.yml`

```yaml
name: Build and Deploy

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build-server:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up JDK 17
        uses: actions/setup-java@v3
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Build with Gradle
        run: ./gradlew :server:shadowJar
      - name: Upload JAR
        uses: actions/upload-artifact@v3
        with:
          name: server-jar
          path: server/build/libs/*.jar

  build-android:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up JDK 17
        uses: actions/setup-java@v3
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Build with Gradle
        run: ./gradlew :app:assembleRelease
      - name: Upload APK
        uses: actions/upload-artifact@v3
        with:
          name: android-apk
          path: app/build/outputs/apk/release/*.apk

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run tests
        run: ./gradlew test
```

### Docker Hub (Optional)

```yaml
- name: Build and push Docker image
  uses: docker/build-push-action@v4
  with:
    context: .
    push: true
    tags: user/smarty-server:latest
```

## ROLLBACK PROCEDURE

### Server Rollback

1. **Identify Last Good Version**
   ```bash
   git log --oneline
   ```

2. **Revert Deployment**
   ```bash
   git revert HEAD
   git push
   ```

3. **Hugging Face Spaces**
   - Space automatically rebuilds
   - Or manually restart

### Android Rollback

1. **Revert Version Code**
   ```kotlin
   versionCode = previous_version
   ```

2. **Rebuild APK**
   ```bash
   ./gradlew :app:assembleRelease
   ```

3. **Deploy to Play Store**
   - Create new release
   - Upload APK
   - Roll out to users

## BUILD TROUBLESHOOTING

### Common Issues

**Gradle Sync Failed:**
```bash
# Clean and rebuild
./gradlew clean
./gradlew build --refresh-dependencies
```

**Android SDK Not Found:**
```bash
# Set ANDROID_HOME
export ANDROID_HOME=/path/to/android/sdk
```

**Docker Build Failed:**
```bash
# Clear Docker cache
docker builder prune
docker build --no-cache -t smarty-server .
```

**Server Start Failed:**
```bash
# Check environment variables
echo $DB_URL
echo $TAVILY_API_KEY

# Check database connection
docker exec -i smarty-db psql -U smarty_user -d smarty_db -c "SELECT 1"
```
