## REMAINING DEBT

### Critical (Fix This Week)

#### 1. Memory Leak in Thinking Cache

**Debt:** Thinking cache not cleared on error/timeout

**Location:** `ThinkingStorageManager.kt`

**Current State:**
```kotlin
fun finalizeAndGetThinking(sessionId: String): String {
    val thinking = getCurrentThinking(sessionId)
    thinkingCache.remove(sessionId)  // Only removed on success
    return thinking
}
```

**Impact:** Memory growth over time, potential OOM

**Fix:**
```kotlin
fun finalizeAndGetThinking(sessionId: String): String {
    return thinkingCache.remove(sessionId)?.toString() ?: ""
}
```

**Effort:** 1 hour
