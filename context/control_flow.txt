# CONTROL FLOW

## Overview

This document traces the control flow through the Smarty system, showing how execution moves through components in response to events and triggers.

## CONTROL FLOW 2: CHAT REQUEST PROCESSING

### SSE Stream Handler

```
GET /chat/stream?query=...&sessionId=...
    │
    ├─> authenticate("firebase")
    │       └─> Verify JWT token
    │
    ├─> sse("/chat/stream") { ... }
    │       │
    │       ├─> Extract parameters
    │       │       ├─> query, sessionId, provider, model
    │       │       └─> timezone, clientTime
    │       │
    │       ├─> Create LLM Provider
    │       │       └─> LlmProviderFactory.create(providerParam, tokenParam)
    │       │
    │       ├─> Load/Create Session
    │       │       ├─> chatRepository.getSession()
    │       │       └─> If new: chatRepository.createSession()
    │       │
    │       ├─> Save User Message
    │       │       └─> chatRepository.saveMessage(role="user")
    │       │
    │       ├─> Load History
    │       │       └─> chatRepository.getHistory(sessionId)
    │       │
    │       ├─> Register Active Session
    │       │       └─> ActiveSessionManager.startSession()
    │       │
    │       ├─> Create ServerAgent
    │       │       └─> With eventEmitter callback for SSE
    │       │
    │       ├─> agent.run(query, sessionId, history, modelOverride)
    │       │       │
    │       │       ├─> withTimeout(30 minutes)
    │       │       │
    │       │       └─> runInternal()
    │       │               │
    │       │               ├─> GoalMemoryManager.initializeWithGoal()
    │       │               │
    │       │               ├─> persistenceManager.loadCheckpoint()
    │       │               │
    │       │               ├─> vectorStore.search()  // RAG
    │       │               │
    │       │               ├─> vectorStore.getRecentContext()  // User profile
    │       │               │
    │       │               ├─> Build Messages
    │       │               │       └─> System prompt + history + context
    │       │               │
    │       │               └─> Agent Loop
    │       │                       │
    │       │                       ├─> llmProvider.stream(messages, tools)
    │       │                       │       │
    │       │                       │       └─> For each chunk:
    │       │                       │               ├─> Emit Processing event
    │       │                       │               ├─> Check for tool calls
    │       │                       │               └─> Emit Result event
    │       │                       │
    │       │                       ├─> Tool Execution
    │       │                       │       ├─> tavilyTool.search()
    │       │                       │       ├─> webScrapeTool.scrape()
    │       │                       │       └─> Emit ToolCall event
    │       │                       │
    │       │                       ├─> Update Thinking Storage
    │       │                       │       └─> ThinkingStorageManager.save()
    │       │                       │
    │       │                       ├─> Progressive Save
    │       │                       │       └─> chatRepository.updateMessageThinking()
    │       │                       │
    │       │                       └─> Check iteration limits
    │       │                               └─> Max 200 iterations, 100 tool calls
    │       │
    │       ├─> Save Assistant Response
    │       │       └─> chatRepository.saveMessage(role="assistant", thinking, toolCalls)
    │       │
    │       └─> ActiveSessionManager.endSession()
    │
    └─> SSE stream complete
```

### Agent Loop Detail

```
while (!done && iterations < MAX_ITERATIONS) {
    │
    ├─> llmProvider.stream(messages, tools)
    │       │
    │       ├─> For each LlmChunk:
    │       │       ├─> if chunk.content != null:
    │       │       │       └─> emit(AgentEvent.Processing(content))
    │       │       │
    │       │       ├─> if chunk.toolCall != null:
    │       │       │       └─> pendingToolCalls.add(chunk.toolCall)
    │       │       │
    │       │       └─> if chunk.usage != null:
    │       │               └─> trackTokenUsage()
    │       │
    │       └─> Return full response content
    │
    ├─> if toolCalls detected:
    │       │
    │       ├─> For each toolCall:
    │       │       ├─> emit(AgentEvent.ToolCall(status="started"))
    │       │       │
    │       │       ├─> Execute tool
    │       │       │       ├─> TavilySearchTool.search()
    │       │       │       ├─> WebScrapeTool.scrape()
    │       │       │       └─> Other tools...
    │       │       │
    │       │       ├─> emit(AgentEvent.ToolCall(status="completed"))
    │       │       │
    │       │       └─> Append tool result to messages
    │       │
    │       └─> Continue loop (LLM processes tool results)
    │
    ├─> if final response complete:
    │       └─> emit(AgentEvent.Result(isFinal=true))
    │
    └─> Check termination conditions
            ├─> LLM indicates done
            ├─> Max iterations reached
            └─> Timeout exceeded
}
```

## CONTROL FLOW 3: RESEARCH SESSION

### Research Agent Flow

```
POST /api/v1/research/start
    │
    ├─> DeepResearchAgent.startResearch(topic)
    │       │
    │       ├─> Create initial ResearchSession
    │       │
    │       └─> Generate clarification questions
    │               └─> 5 predefined questions
    │
    └─> Return session with questions

POST /api/v1/research/{id}/answer
    │
    ├─> DeepResearchAgent.processUserAnswers(session, answers)
    │       │
    │       ├─> Update session status = "researching"
    │       │
    │       ├─> performSearch(session, topic)
    │       │       │
    │       │       ├─> tavilyTool.search(query)
    │       │       │
    │       │       ├─> Parse results
    │       │       │
    │       │       ├─> Create citations
    │       │       │
    │       │       └─> Check context threshold
    │       │               └─> If > 8000 tokens: save to progress file
    │       │
    │       └─> Return updated session
    │
    └─> Return session with search results

[LOOP: Research iterations]
    │
    ├─> Analyze results
    │       └─> Identify knowledge gaps
    │
    ├─> Generate follow-up queries
    │       └─> Based on gaps
    │
    ├─> Execute parallel searches
    │       └─> Up to 10 concurrent searches
    │
    ├─> Scrape top URLs
    │       └─> Up to 5 concurrent scrapes
    │
    ├─> Check timeout
    │       ├─> If > 12 min: send warning
    │       └─> If > 15 min: force complete
    │
    └─> Check user interruption
            └─> Handle direction change

[SYNTHESIS]
    │
    ├─> Read progress file (if exists)
    │
    ├─> Build synthesis prompt
    │       └─> Include all citations + progress
    │
    ├─> llmProvider.generate(messages)
    │       └─> Generate final report
    │
    ├─> Clear progress file
    │
    └─> Create note card with findings
```

## CONTROL FLOW 6: ERROR HANDLING

### Server Error Flow

```
try {
    agent.run()
} catch (e: TimeoutCancellationException) {
    │
    ├─> Log error with metrics
    │
    ├─> emit(AgentEvent.Error(
    │       code = "TIMEOUT",
    │       message = "Operation timed out"
    │   ))
    │
    └─> Return fallback response

} catch (e: Exception) {
    │
    ├─> Log error with stack trace
    │
    ├─> emit(AgentEvent.Error(
    │       code = "INTERNAL_ERROR",
    │       message = e.message?.take(100)
    │   ))
    │
    └─> Return error response
}

finally {
    └─> ActiveSessionManager.endSession()
}
```

### Android Error Flow

```
viewModel.addNote(content)
    │
    ├─> try {
    │       ├─> repository.addNote()
    │       ├─> syncQueue.enqueue()
    │       └─> Update UI state
    │   }
    │
    └─> catch (e: Exception) {
            ├─> Log error
            ├─> Update error state
            └─> Show Snackbar to user
        }
```

## CONTROL FLOW DECISION POINTS

### LLM Provider Selection

```
ProviderRouter.selectProvider(strategy)
    │
    ├─> Check LLM_MODEL_ID env var
    │       └─> If set: return override
    │
    ├─> When strategy == CHEAPEST:
    │       └─> Return gemini-1.5-flash
    │
    ├─> When strategy == FASTEST:
    │       └─> Return gemini-1.5-flash
    │
    ├─> When strategy == SMARTEST:
    │       └─> Return gemini-1.5-pro
    │
    └─> When strategy == BALANCED:
            └─> Return gemini-1.5-flash
```

### Tool Selection

```
ServerAgent: Tool decision in LLM
    │
    ├─> LLM analyzes user intent
    │
    ├─> If "remember/save/note" → memory tool
    │
    ├─> If "remind/timer/alarm" → remind tool
    │
    ├─> If "schedule/calendar" → schedule tool
    │
    ├─> If "search/research/news" → search tool
    │
    ├─> If "generate image" → generate_image tool
    │
    └─> If no tool needed → direct response
```

### Sync Decision

```
SyncWorker.doWork()
    │
    ├─> Check network connectivity
    │       └─> If offline: return retry
    │
    ├─> Check sync_queue for pending ops
    │       ├─> If empty: skip push
    │       └─> If not empty: execute push
    │
    ├─> Fetch last_sync_at
    │
    ├─> Pull changes since last_sync_at
    │       └─> If changes: apply to Room
    │
    └─> Update sync_state
```

## THREADING MODEL

### Server Threading

```
Netty Event Loop (IO threads)
    │
    ├─> Accepts HTTP requests
    │
    └─> Dispatches to coroutine context

Coroutine Scope (Dispatchers.IO)
    │
    ├─> Database operations
    ├─> External API calls
    ├─> File I/O
    └─> LLM streaming

Dispatcher: Default (CPU-bound)
    │
    └─> LLM response processing
        └─> JSON parsing
```

### Android Threading

```
Main Thread (UI)
    │
    ├─> Compose rendering
    ├─> User input handling
    └─> State collection

Coroutine Scope (Dispatchers.IO)
    │
    ├─> Room database operations
    ├─> Network requests (Ktor)
    └─> File operations

Coroutine Scope (Dispatchers.Default)
    │
    └─> Heavy computations
        └─> Search result processing
```

## STATE MACHINES

### Chat Session State

```
NEW → ACTIVE → SUMMARIZING → ARCHIVED
              ↓
          EXPIRED (after 30 days)
```

### Research Session State

```
PLANNING → SEARCHING → SCRAPING → ANALYZING → DEEP_DIVING → SYNTHESIZING → COMPLETED
    ↓          ↓           ↓           ↓            ↓              ↓
  PAUSED   PAUSED      PAUSED      PAUSED       PAUSED         PAUSED
```

### Timer State

```
SET → ACTIVE → TRIGGERED → DISMISSED
              ↓
          SNOOZED → ACTIVE
```

### Generated Image State

```
QUEUED → PROCESSING → COMPLETED → DOWNLOADED
                    ↓
                FAILED
```
