# CODING PATTERNS AND CONVENTIONS

## Overview

This document catalogs coding patterns, conventions, and architectural decisions used throughout the Smarty codebase.

---

## NAMING CONVENTIONS

### File Naming

**Kotlin Files:**
- PascalCase: `MainActivity.kt`, `ServerAgent.kt`
- Suffix by type: `ViewModel.kt`, `Repository.kt`, `Service.kt`

**Test Files:**
- Suffix with `Test`: `NoteRepositoryTest.kt`
- Same package as tested class

**Resource Files (Android):**
- snake_case: `activity_main.xml`, `btn_submit.xml`
- Drawable prefix by type: `ic_launcher.png`, `bg_card.xml`

### Class Naming

**Pattern:** Descriptive name indicating purpose

```kotlin
// ViewModels
SmartyViewModel
ChatViewModel
AudioPlayerViewModel

// Repositories
NoteRepository
ChatRepository
CalendarRepository

// Services
DigestService
VisionService
OrchestratorService

// Agents
ServerAgent
DeepResearchAgent
AdvancedDeepResearchAgent

// Routes (Controllers)
ChatRoutes
ResearchRoutes
DataRoutes
```

### Function Naming

**Pattern:** verb + object, camelCase

```kotlin
// CRUD operations
fun addNote(...)
fun deleteNote(...)
fun updateNote(...)
fun getNoteById(...)

// Actions
fun sendChatMessage(...)
fun startResearch(...)
fun generateImage(...)

// Queries
fun searchNotes(...)
fun findActiveNotes(...)
fun getRecentChats(...)
```

### Variable Naming

**Pattern:** camelCase, descriptive names

```kotlin
// Good
val userId: String
val chatMessages: List<ChatMessage>
val isProcessing: Boolean

// Avoid
val uid: String  // Too abbreviated
val msgs: List<ChatMessage>  // Unclear
val flag: Boolean  // Meaningless
```

### Constant Naming

**Pattern:** SCREAMING_SNAKE_CASE

```kotlin
private const val MAX_EXECUTION_TIME_MS = 30 * 60 * 1000L
private const val DEFAULT_SERVER_URL = "https://..."
private const val TAG = "SmartyApplication"
```

## COROUTINE PATTERNS

### ViewModel Scope

**Pattern:** Use viewModelScope for lifecycle-aware coroutines

```kotlin
class ChatViewModel : ViewModel() {
    fun sendMessage(message: String) {
        viewModelScope.launch {
            try {
                _isSending.value = true
                repository.send(message)
            } catch (e: Exception) {
                _error.value = e.message
            } finally {
                _isSending.value = false
            }
        }
    }
}
```

### Dispatcher Usage

**Pattern:** Use appropriate dispatcher for workload

```kotlin
// IO operations
viewModelScope.launch {
    withContext(Dispatchers.IO) {
        database.query()
    }
}

// CPU-intensive work
viewModelScope.launch {
    withContext(Dispatchers.Default) {
        processLargeData()
    }
}

// UI updates (default)
viewModelScope.launch {
    _uiState.value = newState
}
```

### Flow Collection

**Pattern:** Collect flows in lifecycle-aware scope

```kotlin
LaunchedEffect(Unit) {
    viewModel.notes.collect { notes ->
        // Update UI
    }
}

// Or in ViewModel
init {
    viewModelScope.launch {
        repository.notes.collect { notes ->
            _notes.value = notes
        }
    }
}
```

### Error Handling

**Pattern:** Try-catch with specific error types

```kotlin
try {
    api.call()
} catch (e: HttpException) {
    // Network error
    _error.value = "Network error: ${e.code}"
} catch (e: SerializationException) {
    // Parse error
    _error.value = "Invalid response format"
} catch (e: Exception) {
    // Generic error
    _error.value = "Unexpected error: ${e.message}"
}
```

## COMPOSE PATTERNS

### State Hoisting

**Pattern:** Lift state to parent composable

```kotlin
// Parent holds state
@Composable
fun HomeScreen(viewModel: SmartyViewModel = hiltViewModel()) {
    val notes by viewModel.notes.collectAsState()
    val isLoading by viewModel.isNotesLoading.collectAsState()
    
    NoteList(
        notes = notes,
        isLoading = isLoading,
        onNoteClick = viewModel::selectNote,
        onRefresh = viewModel::refreshNotes
    )
}

// Child is stateless
@Composable
fun NoteList(
    notes: List<Note>,
    isLoading: Boolean,
    onNoteClick: (Note) -> Unit,
    onRefresh: () -> Unit
) {
    // Render UI
}
```

### Side Effects

**Pattern:** Use LaunchedEffect for side effects

```kotlin
@Composable
fun ChatScreen(viewModel: ChatViewModel) {
    val sessionId by viewModel.sessionId.collectAsState()
    
    // Connect to stream when session changes
    LaunchedEffect(sessionId) {
        viewModel.connectToStream(sessionId)
    }
    
    // Cleanup on dispose
    DisposableEffect(Unit) {
        onDispose {
            viewModel.disconnect()
        }
    }
}
```

### Remember Usage

**Pattern:** Remember computed values

```kotlin
@Composable
fun NoteCard(note: Note) {
    // Remember formatted date
    val formattedDate = remember(note.createdAt) {
        formatDate(note.createdAt)
    }
    
    // Remember derived state
    val isOverdue = remember(note.dueDate) {
        note.dueDate < System.currentTimeMillis()
    }
}
```

### Ktor Route Organization

**Pattern:** Group routes by feature

```kotlin
fun Application.configureChatRoutes() {
    routing {
        authenticate("firebase") {
            sse("/chat/stream") { ... }
            post("/chat/query") { ... }
            post("/chat/events") { ... }

fun Application.configureResearchRoutes(agent: DeepResearchAgent) {
    routing {
        authenticate("firebase") {
            route("/api/v1/research") {
                post("/start") { ... }
                post("/{id}/answer") { ... }
            }
        }
    }
}
```

### SSE Streaming

**Pattern:** Server-Sent Events for real-time updates

```kotlin
sse("/chat/stream") {
    val eventEmitter: suspend (AgentEvent) -> Unit = { event ->
        try {
            val eventType = when(event) {
                is AgentEvent.Processing -> "processing"
                is AgentEvent.ToolCall -> "tool_call"
                is AgentEvent.Result -> "result"
                is AgentEvent.Error -> "error"
            }
            send(ServerSentEvent(
                data = json.encodeToString(event),
                event = eventType
            ))
        } catch (e: Exception) {
            logger.warn("Failed to send event: ${e.message}")
        }
    }
    
    // Use emitter in agent
    agent.run(query, sessionId, eventEmitter)
}
```

### Plugin Pattern

**Pattern:** Ktor plugins for cross-cutting concerns

```kotlin
// Authentication plugin
fun Application.configureSecurity() {
    install(Authentication) {
        bearer("firebase") {
            authenticate { token ->
                verifyFirebaseToken(token)
            }
        }
    }
}

// Rate limiting plugin
install(RateLimit) {
    register(RateLimitName("chat")) {
        rateLimiter(limit = 120, refillPeriod = 1.minutes)
    }
}
```

### Repository Pattern (Server)

**Pattern:** Same as Android, server-side

```kotlin
class NoteRepository(private val dataSource: DataSource) {
    suspend fun getAll(userId: String): List<Note> = withContext(Dispatchers.IO) {
        dataSource.connection.use { conn ->
            conn.prepareStatement("""
                SELECT * FROM notes 
                WHERE user_id = ? AND deleted_at IS NULL
            """).use { stmt ->
                stmt.setString(1, userId)
                stmt.executeQuery().map { rs ->
                    Note.fromResultSet(rs)
                }
            }
        }
    }
}
```

## DATA CLASS PATTERNS

### Immutable Data Classes

**Pattern:** Use val, copy for modifications

```kotlin
data class Note(
    val id: String,
    val title: String,
    val content: String,
    val isPinned: Boolean,
    val createdAt: Long,
    val updatedAt: Long
) {
    // Derived properties
    val wordCount: Int get() = content.length
    
    // Modification methods
    fun withTitle(newTitle: String) = copy(title = newTitle)
    fun withContent(newContent: String) = copy(
        content = newContent,
        updatedAt = System.currentTimeMillis()
    )
}
```

### Sealed Classes for State

**Pattern:** Exhaustive when expressions

```kotlin
sealed class AgentEvent {
    data class Processing(val content: String) : AgentEvent()
    data class ToolCall(val toolName: String, val status: String) : AgentEvent()
    data class Result(val content: String, val isFinal: Boolean) : AgentEvent()
    data class Error(val message: String) : AgentEvent()
}

// Usage
when (event) {
    is AgentEvent.Processing -> showThinking(event.content)
    is AgentEvent.ToolCall -> showToolStatus(event.toolName, event.status)
    is AgentEvent.Result -> appendResponse(event.content)
    is AgentEvent.Error -> showError(event.message)
}
```

### Serialization Annotations

**Pattern:** Kotlinx serialization with serial names

```kotlin
@Serializable
data class AgentCommand(
    @SerialName("command_id") val commandId: String,
    @SerialName("note_id") val noteId: String,
    @SerialName("is_final") val isFinal: Boolean
)
```

## ERROR HANDLING PATTERNS

### Result Type

**Pattern:** Explicit success/failure

```kotlin
sealed class Result<out T> {
    data class Success<T>(val data: T) : Result<T>()
    data class Error(val message: String, val code: String? = null) : Result<Nothing>()
}

suspend fun addNote(note: Note): Result<Note> {
    return try {
        Result.Success(repository.add(note))
    } catch (e: Exception) {
        Result.Error(e.message ?: "Unknown error")
    }
}
```

### Custom Exceptions

**Pattern:** Specific exception types

```kotlin
class AuthenticationException(message: String) : Exception(message)
class NotFoundException(message: String) : Exception(message)
class ValidationException(message: String, val field: String) : Exception(message)
class RateLimitException(message: String) : Exception(message)
```

### Try-Catch-Finally

**Pattern:** Resource cleanup in finally

```kotlin
val connection = dataSource.connection
try {
    // Use connection
} catch (e: Exception) {
    logger.error("Operation failed", e)
    throw e
} finally {
    connection.close()
}
```

## LOGGING PATTERNS

### Structured Logging

**Pattern:** JSON format with context


### Log Levels

**Pattern:** Appropriate level for message type

```kotlin
logger.debug("Detailed debugging info")  // Development
logger.info("Normal operation message")  // Production baseline
logger.warn("Potential issue, continuing")  // Recoverable

```

**Pattern:** Track requests across services

```kotlin

// Include in all logs

    "Processing request"
    "requestId" to requestId
}
```

## TESTING PATTERNS

### Arrange-Act-Assert

**Pattern:** Clear test structure

```kotlin
@Test
fun `addNote should add note to list`() = runTest {
    // Arrange
    val noteContent = "Test note"
    
    // Act
    viewModel.addNote(noteContent, emptyList())
    testDispatcher.scheduler.advanceUntilIdle()
    
    // Assert
    assertEquals(1, viewModel.notes.value.size)
    assertEquals(noteContent, viewModel.notes.value.first().content)
}
```

### Test Naming

**Pattern:** Descriptive names with backticks

```kotlin
@Test
fun `chat stream should require authentication`() = runTest { ... }

@Test
fun `research agent should ask clarification questions`() = runTest { ... }

@Test
fun `sync push should update server with local changes`() = runTest { ... }
```

### Mock Usage

**Pattern:** Mock external dependencies

```kotlin
@Test
fun `sendMessage should call repository`() = runTest {
    // Given
    val mockRepository = MockRepository()
    val viewModel = ChatViewModel(mockRepository)
    
    // When
    viewModel.sendMessage("Hello")
    
    // Then
    assertTrue(mockRepository.sendCalled)
    assertEquals("Hello", mockRepository.lastMessage)
}
```

## PERFORMANCE PATTERNS

### Lazy Loading

**Pattern:** Load data on demand

```kotlin
class LazyDecompressor {
    private val cache = ConcurrentHashMap<String, ByteArray>()
    
    fun decompress(key: String): ByteArray {
        return cache.computeIfAbsent(key) {
            // Expensive decompression
            decompressFile(key)
        }
    }
}
```

### Caching

**Pattern:** Cache expensive operations

```kotlin
class LlmCache {
    private val cache = ConcurrentHashMap<LlmCacheKey, LlmResponse>()
    
    suspend fun getOrPut(key: LlmCacheKey, compute: suspend () -> LlmResponse): LlmResponse {
        return cache.getOrPut(key) {
            compute()
        }
    }
}
```
