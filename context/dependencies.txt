## Dependency Analysis

### Dependency Count

| Module | Direct Dependencies | Test Dependencies |
|--------|---------------------|-------------------|
| app | ~40 | ~10 |
| common | ~3 | ~1 |
| server | ~20 | ~2 |

### Potential Issues

1. **Kotlin Version Mismatch:**
   - Root forces 2.1.21
   - Server build uses 2.1.0 in plugins
   - Risk: Runtime incompatibilities

2. **Duplicate Dependencies:**
   - kotlinx.serialization.json in all 3 modules
   - kotlinx.coroutines.core in all 3 modules
   - ktor.client.* in both app and server

3. **Firebase BOM Usage:**
   - App uses Firebase BOM
   - Server uses firebase-admin directly
   - Risk: Version mismatches

4. **Exposed ORM Version:**
   - No explicit version in server build
   - Relies on version catalog
   - Risk: Unexpected version changes

### Recommendations

1. Align Kotlin plugin versions (2.1.0 vs 2.1.21)
2. Consider centralizing common dependencies in platform convention
3. Add explicit versions for critical dependencies
4. Review Firebase BOM alignment between app and server
