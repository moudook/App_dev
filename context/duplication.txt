### 6. QueryHelper.kt

**Purpose:** Consistent SQL query construction

**Features:**
- Fluent query builder
- Type-safe builders (SELECT, UPDATE, INSERT, DELETE)
- Common query templates
- Automatic parameter binding

**Adoption:**
```kotlin
// Before
val sql = """
    SELECT * FROM notes
    WHERE user_id = ? AND deleted_at IS NULL
    ORDER BY updated_at DESC
    LIMIT ?
""".trimIndent()
conn.prepareStatement(sql).use { stmt ->
    stmt.setObject(1, UUID.fromString(userId))
    stmt.setInt(2, limit)
    // ...
}

// After
val results = QueryBuilder.select("notes")
    .whereUser(userId)
    .whereIsNull("deleted_at")
    .orderBy("updated_at DESC")
    .limit(limit)
    .execute(conn) { rs -> mapRow(rs) }
```
