## SERVER ENVIRONMENT VARIABLES

### Required Variables

| Variable | Description | Example |
|----------|-------------|---------|
| DB_URL | PostgreSQL JDBC connection URL | `jdbc:postgresql://localhost:5432/smarty_db` |
| DB_USER | Database username | `smarty_user` |
| DB_PASSWORD | Database password | `smarty_pass` |
| TAVILY_API_KEY | Tavily search API key | `tvly-...` |
| KREA_API_KEY | Krea AI image generation key | `krea-...` |

### Conditional Variables

| Variable | Required When | Description | Example |
|----------|---------------|-------------|---------|
| GEMINI_API_KEY | Using Gemini provider | Google Gemini API key | `AIza...` |
| OPENAI_API_KEY | Using OpenAI provider | OpenAI API key | `sk-...` |

### Optional Variables

| Variable | Default | Description |
|----------|---------|-------------|
| ACTIVE_PROVIDER | GEMINI | LLM provider (GEMINI or OPENAI) |
| LLM_MODEL_ID | (auto) | Override model selection |
| SERVER_PORT | 7860 | Server listening port |
| DB_URL | (none) | Database connection string |

**File:** `app/build.gradle.kts`

```kotlin

    defaultConfig {
        applicationId = "com.example.smarty"
        minSdk = 26
        targetSdk = 35
        versionCode = 5
        versionName = "3.2.0"
```

## DOCKER CONFIGURATION

### Dockerfile

**Location:** `Dockerfile`

**Build Stages:**
1. `deps` - Download dependencies
2. `builder` - Build shadow JAR
3. Runtime - JRE with application

**Runtime Configuration:**
```dockerfile
ENV SERVER_PORT=7860
EXPOSE 7860

CMD ["java", "-Xmx384m", "-XX:+UseG1GC", "-XX:MaxRAMPercentage=80.0", 
     "-XX:+UseStringDeduplication", "-jar", "app.jar"]
```

**Security:**
```dockerfile
RUN addgroup -S appgroup && adduser -S -G appgroup -u 1000 user
USER user
```

### Docker Compose

**File:** `docker-compose.yml`

```yaml
services:
  db:
    image: ankane/pgvector
    ports:
      - "5432:5432"
    environment:
      - POSTGRES_DB=smarty_db
      - POSTGRES_USER=smarty_user
      - POSTGRES_PASSWORD=smarty_pass
    volumes:
      - db_data:/var/lib/postgresql/data
      - ./init-db.sql:/docker-entrypoint-initdb.d/init-db.sql

volumes:
  db_data:
```

## CONFIGURATION VALIDATION

### Startup Checks

**Recommended additions:**
```kotlin
fun validateConfiguration() {
    val requiredVars = listOf("DB_URL", "DB_USER", "DB_PASSWORD", "TAVILY_API_KEY")
    val missing = requiredVars.filter { System.getenv(it).isNullOrBlank() }
    
    if (missing.isNotEmpty()) {
        throw IllegalStateException("Missing required environment variables: $missing")
    }
}
```

### Health Check Enhancements

**Recommended additions:**
```kotlin
get("/health/detailed") {
    val dbHealthy = checkDatabase()
    val llmHealthy = checkLlmProvider()
    val searchHealthy = checkTavily()
    
    if (dbHealthy && llmHealthy && searchHealthy) {
        call.respond(HttpStatusCode.OK, HealthStatus.OK)
    } else {
        call.respond(HttpStatusCode.ServiceUnavailable, HealthStatus.Degraded)
    }
}
```

## SENSITIVE DATA HANDLING

### Best Practices Followed

1. **Environment Variables for Secrets**
   - API keys from env vars
   - Not hardcoded

2. **Encrypted Storage**
   - Android: EncryptedSharedPreferences
   - Server: Depends on deployment

3. **Git Ignore**
   - `local.properties`
   - `google-services.json` (should be)
   - `_private/` directory

### Recommendations

1. **Add .gitignore Rules**
   ```
   google-services.json
   local.properties
   .env
   *_secret*.kts
   ```

2. **Use Secret Management**
   - Hugging Face Spaces secrets
   - Consider HashiCorp Vault for production

3. **Rotate Credentials Regularly**
   - API keys
   - Database passwords
   - Firebase credentials
