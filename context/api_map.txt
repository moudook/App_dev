# API MAP

## Overview

This document catalogs all API endpoints exposed by the Smarty server, including request/response formats and authentication requirements.

---

## BASE CONFIGURATION

**Server URL:** Configurable (default: `http://localhost:7860`)

**Authentication:** Firebase JWT Bearer Token

**Header Format:**
```
Authorization: Bearer <firebase_id_token>
```

**Content Type:**
```
Content-Type: application/json
Accept: text/event-stream (for SSE endpoints)
```

---

## HEALTH & MONITORING

### GET /health

**Purpose:** Server health check

**Authentication:** None (public)

**Request:**
```http
GET /health HTTP/1.1
Host: your-server.hf.space
```

**Response:**
```json
{
    "status": "ok",
    "module": "smarty-server",
    "timestamp": 1234567890,
    "uptime_seconds": 3600
}
```

**Status Codes:**
- `200 OK` - Server healthy
- `503 Service Unavailable` - Server unhealthy

---

**Purpose:** Prometheus metrics endpoint

## CHAT ENDPOINTS

### GET /chat/stream

**Purpose:** SSE streaming for chat responses

**Authentication:** Required (Firebase JWT)

**Request:**
```http
GET /chat/stream?query=Hello&sessionId=uuid-123 HTTP/1.1
Host: your-server.hf.space
Authorization: Bearer <token>
```

**Query Parameters:**
| Parameter | Required | Description |
|-----------|----------|-------------|
| query | Yes | User message content |
| sessionId | No | Chat session ID (creates new if omitted) |
| provider | No | Provider strategy (CHEAPEST, FASTEST, SMARTEST, BALANCED) |
| model | No | Specific model override |
| token | No | API key override for custom providers |
| timezone | No | User timezone (e.g., "America/New_York") |
| clientTime | No | Client timestamp in epoch millis |

**Response:** `text/event-stream`

**Event Types:**
```
event: processing
data: {"eventId":"uuid","timestamp":123,"content":"Thinking..."}

event: tool_call
data: {"eventId":"uuid","timestamp":123,"toolName":"web_search","displayName":"Web Search","status":"started"}

event: result
data: {"eventId":"uuid","timestamp":123,"content":"Response text","isFinal":false}

event: command
data: {"eventId":"uuid","timestamp":123,"command":{"type":"set_timer","name":"Timer","timeStr":"10 minutes"}}

event: error
data: {"eventId":"uuid","timestamp":123,"message":"Error message","code":"INTERNAL_ERROR"}
```

**Status Codes:**
- `200 OK` - Stream started
- `401 Unauthorized` - Invalid/missing auth token
- `429 Too Many Requests` - Rate limit exceeded

### POST /chat/query

**Purpose:** Chat with file attachments (larger payloads)

**Authentication:** Required

**Request:**
```http
POST /chat/query HTTP/1.1
Host: your-server.hf.space
Authorization: Bearer <token>
Content-Type: application/json

{
    "query": "Analyze this document",
    "sessionId": "uuid-123",
    "fileContext": "Extracted text from PDF...",
    "attachments": [
        {"type": "pdf", "name": "document.pdf", "mimeType": "application/pdf"}
    ],
    "timezone": "America/New_York",
    "clientTime": 1234567890
}
```

**Response:** Same SSE format as GET /chat/stream

---

### POST /chat/events

**Purpose:** Submit client events (tool results, context updates)

**Authentication:** Required

**Request:**
```http
POST /chat/events?sessionId=uuid-123 HTTP/1.1
Host: your-server.hf.space
Authorization: Bearer <token>
Content-Type: application/json

{
    "type": "tool_result",
    "commandId": "cmd-uuid",
    "result": "Timer set for 10 minutes",
    "isError": false
}
```

**Event Types:**
- `tool_result` - Tool execution result
- `active_notes_response` - Active notes context
- `search_results_response` - Search results
- `recall_results_response` - Knowledge recall
- `calendar_events_response` - Calendar data
- `screen_context_response` - Current screen context

**Response:**
```json
{
    "success": true
}
```

**Status Codes:**
- `200 OK` - Event processed
- `400 Bad Request` - Invalid event format
- `401 Unauthorized` - Invalid auth

POST /api/v1/research/start HTTP/1.1
Host: your-server.hf.space

}
```

**Response:**

{
    "id": "research-uuid",

    "status": "asking_questions",
    "clarificationQuestions": [
        "What specific aspects are you most interested in?",
        "Are there any particular time periods or regions to focus on?",
        "What type of information do you need?",
        "Are there any specific questions you want answered?",
        "Do you need current information or historical context?"
    ],
    "userAnswers": {},
    "researchPlan": null,
    "searchQueries": [],
    "citations": [],

```

**Status Codes:**

### GET /api/v1/research/{id}/timeout

**Purpose:** Check research session timeout status

**Authentication:** Required

**Request:**
```http
GET /api/v1/research/research-uuid/timeout HTTP/1.1
Host: your-server.hf.space
Authorization: Bearer <token>
```

**Response:**
```json
{
    "status": "CONTINUE",
    "elapsed": 600000
}
```

**Status Values:**
- `CONTINUE` - Research can continue
- `WARNING` - 12-minute warning (3 minutes remaining)
- `FORCE_COMPLETE` - 15-minute limit reached

## RATE LIMITS

| Endpoint Category | Limit | Window |
|-------------------|-------|--------|
| Chat | 120 requests | 1 minute |
| Processing | 30 requests | 1 minute |
| Research | 10 requests | 1 minute |
| Data (CRUD) | 60 requests | 1 minute |
| Sync | 30 requests | 1 minute |
| Global (fallback) | 100 requests | 1 minute |

**Rate Limit Headers:**
```
X-RateLimit-Limit: 120
X-RateLimit-Remaining: 119
X-RateLimit-Reset: 1234567890
```

**429 Response:**
```json
{
    "error": "Rate limit exceeded",
    "retryAfter": 60
}
```

## ERROR RESPONSES

### Standard Error Format

```json
{
    "error": "Error message",
    "code": "ERROR_CODE",
    "details": {...}
}
```

### Common Error Codes

| Code | HTTP Status | Description |
|------|-------------|-------------|
| UNAUTHORIZED | 401 | Invalid/missing auth token |
| FORBIDDEN | 403 | Insufficient permissions |
| NOT_FOUND | 404 | Resource not found |
| BAD_REQUEST | 400 | Invalid request format |
| RATE_LIMITED | 429 | Too many requests |
| INTERNAL_ERROR | 500 | Server error |
| TIMEOUT | 504 | Request timeout |
