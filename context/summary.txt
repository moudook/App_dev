## VERIFIED PATTERNS

### Pattern 1: UUID Conversion (NEW)

**Found in:** All repository files

**Before:**
```kotlin
// Repeated 100+ times across repositories
stmt.setObject(1, UUID.fromString(userId))
stmt.setObject(2, UUID.fromString(noteId))
```

**After:**
```kotlin
import com.example.smarty.server.utils.toUuid

stmt.setObject(1, userId.toUuid())
stmt.setObject(2, noteId.toUuid())
```

**Benefit:** Better error messages, null-safe variants, validation helpers

---

### Pattern 2: SQL Query Construction (NEW)

**Found in:** All repository files

**Before:**
```kotlin
// Repeated in NoteRepository, ChatRepository, CalendarRepository, etc.
val sql = """
    SELECT * FROM notes
    WHERE user_id = ? AND deleted_at IS NULL
    ORDER BY updated_at DESC
    LIMIT ?
""".trimIndent()
conn.prepareStatement(sql).use { stmt ->
    stmt.setObject(1, UUID.fromString(userId))
    stmt.setInt(2, limit)
    // ...
}
```

**After:**
```kotlin
import com.example.smarty.server.utils.QueryBuilder

val results = QueryBuilder.select("notes")
    .whereUser(userId)
    .whereIsNull("deleted_at")
    .orderBy("updated_at DESC")
    .limit(limit)
    .execute(conn) { rs -> mapRow(rs) }
```

**Benefit:** Type-safe, fluent API, automatic parameter binding

---

### Pattern 3: Inline System Prompts

**Found in:** ServerAgent.kt, DeepResearchAgent.kt, AdvancedDeepResearchAgent.kt

**Before:**
```kotlin
// 500+ lines of inline prompt in ServerAgent.kt
val systemMessage = LlmMessage(
    role = LlmMessage.Role.SYSTEM,
    content = """<massive prompt with all guidelines>"""
)
```

**After:**
```kotlin
import com.example.smarty.server.agent.ExtendedAgentPrompts

val systemMessage = LlmMessage(
    role = LlmMessage.Role.SYSTEM,
    content = ExtendedAgentPrompts.getSystemPrompt(AgentType.CHAT)
)
```

**Benefit:** Single source of truth, easier to update, testable
